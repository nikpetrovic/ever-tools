# Presentation Materials

**Type:** Feature  
**Status:** Complete

## Goal

Create two standalone HTML presentation files:
- `resources/presentation/index.html` — marketing/website page
- `resources/presentation/docs.html` — user documentation

## Design Decisions

- No real screenshots; HTML/CSS mockups reproduce the app UI using its actual design tokens
- Three platform frames on marketing page (macOS, Windows, Linux) side by side
- Rich email content with "ever" theme throughout, words highlighted in accent orange
- Tagline: "Whatever you do — send it. **WhatEver** Mail."
- Self-contained HTML files, Google Fonts CDN only (no build step)
